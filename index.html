About

I build the logic behind the screen: programs that are structured, reliable and easy to maintain.

I’m Kenneth Aurelio, a second-year Computer Science student at Pambayang Dalubhasaan ng Marilao. My strengths are backend development, problem-solving and database design, and I enjoy turning a messy requirement into clean, working logic.

I write programs in C++, Java and C# using object-oriented principles, design and query relational databases with SQL, and connect software to hardware through Arduino projects. With a team, I built ARK, a library management system backed by MySQL, and I keep a public SQL reference guide on GitHub.

My work is backed by Oracle certifications in Java Fundamentals and Database Foundation: SQL, a Cisco Computer Hardware credential, and a 3rd place finish in a programming competition. I’m looking for projects, internships and collaborations where I can contribute to backend and data-driven systems while learning from experienced teams.
